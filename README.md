# "HuertoHogar"

## Descripción

HuertoHogar es un pagina web académica desarrollado para la asignatura **DSY1104 - Desarrollo Fullstack II**.

El proyecto consiste en el desarrollo de un sitio web orientado a la venta de productos frescos, orgánicos y lácteos. El sitio permite visualizar productos, registrarse, iniciar sesión y utilizar un carrito de compras.

## Objetivo

Desarrollar una página web utilizando tecnologías Frontend para presentar los productos de HuertoHogar y entregar una experiencia de navegación e interacción sencilla para los usuarios.

## Funcionalidades

- Página principal de HuertoHogar.
- Navegación entre las diferentes páginas del sitio.
- Visualización de productos.
- Imágenes de los productos.
- Video relacionado con HuertoHogar.
- Formulario de registro de usuarios.
- Formulario de inicio de sesión.
- Validación de formularios mediante JavaScript.
- Mensajes personalizados de error.
- Uso de `autocomplete` en los formularios.
- Carrito de compras.
- Selección de cantidad de productos.
- Cálculo automático del total del carrito.
- Eliminación de productos del carrito.

## Tecnologías utilizadas

### HTML5

Utilizado para crear la estructura y contenido de las páginas web mediante elementos semánticos.

### CSS3

Utilizado para el diseño y presentación visual del sitio web.

### JavaScript

Utilizado para implementar la validación de formularios y la funcionalidad del carrito de compras.
